# Deployment management v0.1 fixture scope

The complete administrator requests are documented in
[the maintained publication contract](../../../docs/development/online-deployment-publications-v0.1.md).
Fixtures reuse the existing deployment-intent-feasibility/v0.3 source schema. They are
explicit synthetic software declarations, not robot measurements, localization, hardware
attestation or motion permission. Version two adds a declared software endpoint; normal
Node Protocol registration, current readiness and Control Commit/Bind remain required.

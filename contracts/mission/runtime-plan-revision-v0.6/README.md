# Runtime revision v0.6 coordination permission

Only `authorize-coordination` uses this schema; policy, output, Review and switching retain their
original commands. Declare purpose before output/claim/Review. The actual Controller freezes all
current attempts, membership, original support and same-tenant higher-priority resource blockers.
Review covers the immutable coordination digest alongside original Memory context. Complete
original stop/revoke and normal Control creation remain mandatory. Handoff/regrasp requires device
observation and original Memory transfer; software-process evidence cannot satisfy it.
See [ADR-0210](../../../docs/decisions/0210-reviewed-execution-coordination.md).

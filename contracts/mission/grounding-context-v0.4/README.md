# Mission grounding context v0.4

Extends v0.2/v0.3 with explicitly admitted, hash-verified reported-origin content.
The complete manifest provenance and exact canonical content are digest-bound in
the immutable context. `VerifiedReportedOrigin` is neither current localization
nor authorization to navigate. Metadata-only Memory keeps its earlier encoding.
Prior context readers refuse v0.4, including wrapper downgrade attempts containing
content. The v0.4 Mission Request schema admits this new nested generation.

The initial decoder supports only `roboguide.reported-origin/v0.1`, Global scope,
experience kind and `reported-origins` provider with original Node/Task provenance.
Private/local or Group Memory is not made Global by this contract. File bounds,
canonical bytes, digest, size and provenance validation are mandatory in Python;
the JSON schema does not independently prove these cross-field invariants.

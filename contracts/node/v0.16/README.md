# Node catalog v0.16

Node Contract v0.13 and config v0.14 explicitly negotiate typed quantitative Compute pools.
CanonicalInvocation tag 8 contains the exact closed original grant array outside model parameters.
Resource tags 6 and 7 declare allocation mode and versioned unit class. Historical tags retain their meanings.
The closed [grant schema](resource-allocation-grant.schema.json) describes each array item;
Control and Node additionally verify its canonical parent hash, exact owner and cross-field bounds.

Controller wrapper v56, Node journal v14 and recovery v0.24 retain original grants, Context limits,
borrowers and Unknown across restart. Logical units do not assert OS/GPU/device or realtime isolation.
See [ADR-0206](../../../docs/decisions/0206-quantitative-resource-allocation.md).

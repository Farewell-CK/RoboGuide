# Replicated Federation process inputs v0.1

The optional closed `federation` field supplies the actual declared domain, existing authorization
JSON and optional root peer-profile JSON to an owned replicated Controller. Initial bounded file
bytes enter its original common policy digest; physical input paths confer no business permission.
Absent inputs preserve prior policy identity. Raw inherited variables cannot bypass environment
clearing or enable unsupported application generations.

Actual Node/Operator/Artifact mTLS and owned-content configuration remain required. Each domain
retains independent Raft, normal Control and local process authority. The application still owns
current principals, immutable nonces, original budgets, durable decisions and independent goals.
See [ADR-0214](../../../docs/decisions/0214-replicated-federation-deployment.md).

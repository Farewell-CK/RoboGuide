# Explicit recovery v0.30

This generation retains every v0.29 Federation, scoped Memory, coordination, time/calendar and
earlier recovery obligation. It additionally accepts explicit Replica parent11 and original online
Archive journal v0.3 / recovery projection v0.2 / complete-content v4. The Controller wrapper remains
v60; no Node, MissionPlan, Memory provider or event contract changes are implied.

Missing journals or markers, old-profile demotion, lost original pending commands, changed first
clocks, absent completion manifests, missing same-owner package bytes and source tombstone conflicts
refuse publication/verify/restore. All actual complete declared Root/CAS and current Memory references
remain mandatory. Released history does not require deleted payload content.

Archive package bytes are independently checked against original prefix, checkpoint, Catalog and
qualified inputs. Restoring a package does not admit another command, renew its clock, resend an
uncertain effect, start a service, or establish a device/physical continuity fact.

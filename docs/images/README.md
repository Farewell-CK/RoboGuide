# 文档图片资源

本目录集中保存出现在 README、架构说明和后续设计文档中的图片资源。

## 命名约定

- 使用能够表达内容的英文小写文件名；
- 使用连字符分隔单词；
- 对应版本写入文件名，例如 `architecture-v1.1.png`；
- 文档引用使用相对路径，避免依赖根目录中的随机文件名；
- 新增图片时同步在使用它的文档中写明图片用途和来源。

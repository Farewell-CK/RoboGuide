## 版本规则

改变一级模块职责、状态权威、Proposal / Commit 语义、Execution Group 定义或 Recovery 层级时，先更新当前版本基线，再同步总体架构图、README、PPT、论文和实现文档。纯实现选型不创建新的架构版本，除非它反向改变系统语义。

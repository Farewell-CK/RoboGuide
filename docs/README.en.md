## How to identify authority

Current guides explain code and link directly to the owning modules. Versioned references retain their original contract interpretation and source language, with bilingual reader entrypoints. ADRs and dated acceptance/audit records retain their original bytes and dates. Implementation, software testing, physical outcomes and long-term SLO are separate claims.

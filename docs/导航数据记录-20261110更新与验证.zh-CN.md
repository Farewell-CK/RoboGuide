# 2026-11-10 更新与验证

## 手机操作

录制由导航控制：点击现有 **开始导航** 后先建立档案，再开始查询路线；点击 **结束导航** 后封存。界面已移除单独的“开始数据记录 / 结束数据记录”。路线查询失败也会保存失败原因。规划等待时同一按钮显示“取消导航”；取消后不会被晚到的路线回复重新启动。

千问识别指令不再单独建立档案。已有导航记录时，相关调用继续写入当前档案。多阶段导航在实际开始第一个阶段时建档，最后阶段结束或取消才封存。

- 起终点：记录起点栏文字、导航请求时的手机定位/精度/时间/WGS84，以及终点文字、地图解析坐标/GCJ02、路线及步骤。

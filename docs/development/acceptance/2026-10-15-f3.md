## 当前实现调用链

- 管理证书/显式本地管理员 → typed registry command → expected revision + 原主体/内容去重 →
  私有 Control candidate → checkpoint/authority journal Commit → 后续消费。
- Node 原始 State observation → source epoch/tenant/TTL → 显式 Belief producer（可选） →
  immutable decision snapshot → Match/Commit/Bind/Rebind/readiness → 持久 Execute intent →
  当前时钟/State 再检查 → 正式 Node Protocol。
- 独立 verifier → 当前来源/tenant/完整 attempt/plan/predicate 检查 → 实际 CAS digest/长度 →
  receipt + State/event projection → 本地完成及 satisfaction gate → Orchestration → Control release。
  负面/过期持续观察进入全 Group stop/hold；终态后的报告保留 incident。
- MI 实际 transport call → request/response/model metadata digest → trace context →
  同 SQL 事务的 Request/provenance → indexed original configuration fence → 分页 readonly query。

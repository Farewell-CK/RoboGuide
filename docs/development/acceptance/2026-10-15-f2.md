## 当前调用链

- HTTP command → authenticated scope → Request save + progress journal SQL → durable response；
  pending observe/reconcile 不重新执行原 command。
- Operator mTLS → 解析后的当前 grant/revision → application candidate → Control registry/tenant
  → checkpoint/journal/quorum Commit → transport projection；失败不先发布。
- Node TLS leaf → Hello/当前 session → Control session anchor → tenant-scoped Matching/Commit
  → Bind/Rebind/continuation → transport 每次命令/事实检查。撤销保留资源所有权。
- CSPRNG challenge → native quote/signature/PCR verifier → 原 proof/report → checkpoint → restore
  复核；签名有效不成为硬件真实性证据。

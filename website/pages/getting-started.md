# 安装与首次使用

## 进入 NAVI

1. 从项目维护者获取整合测试安装包，核对版本后安装。
2. 打开 RoboGuide·NAVI，在“导航”页选择“NAVI 室内导航”。
3. 按手机系统提示授予导航所需的相机、传感器等权限。
4. 首次进入填写视觉服务地址、数据库项目地址和公开客户端密钥。
5. 使用 NAVI 数据库账号登录，检查地图和路线是否可见。

RoboGuide 外层的本地模拟登录，与 NAVI 内层的 Supabase 真实账号登录不同。
整合包不会自动继承独立 NAVI 的本机配置或登录状态。

## 三项配置分别是什么

| 配置 | 用途 | 从哪里获取 |
| --- | --- | --- |
| 视觉服务地址 | DINOv2 特征提取和障碍请求入口 | 项目维护者提供的当前可达地址 |
| Supabase 项目地址 | 登录、地图、路线及相关数据 | 项目维护者提供的项目或代理地址 |
| 公开客户端密钥 | 手机端访问项目的公开凭据 | 与该数据库项目匹配的客户端配置 |

公开客户端密钥与数据库管理员密钥不同，不能把 service_role 等管理凭据填写到手机端。
具体服务器地址取决于采用的网络方案，本文档不把某台机器的临时地址写为通用默认值。

## 首次检查

先确认登录、地图管理和路线图片能正常加载，再进行 [实地测试](testing.md)。
如果使用 Tailscale 私网地址，需要手机和服务器在有权互访的网络中在线。
账号角色决定哪些地图和管理操作可见；登录成功本身不代表拥有管理员权限。

# 同事测试流程

## 开始前

- 从维护者获取当前测试包、两个服务地址和匹配的公开客户端密钥。
- 使用自己的 NAVI 账号；需要管理员功能时由维护者按账号授予对应角色。
- 按采用的网络方案准备连接，确认视觉服务及地图管理分别正常。
- 首次测试由熟悉路线的人陪同，保持摄像头朝向与录制时接近。

## 依次测试

| 阶段 | 操作 | 观察与记录 |
| --- | --- | --- |
| 登录与地图 | 进入 NAVI、登录、加载地图和路线 | 各阶段等待时长、图片是否齐全 |
| 起点定位 | 在录制起点持稳手机识别 | 请求时长、参考图片、分数及确认状态 |
| 出发与直行 | 校准方向后沿路线行走 | 方向指示、参考点推进、语音字幕 |
| 转弯 | 按路线到达拐角并观察确认 | 转向提示、是否卡点、箭头方向 |
| 到达 | 走到录制终点并完成确认 | 是否出现到达页面及语音 |
| 障碍提醒 | 先空走廊，再拍摄椅子、箱子及静止行人 | 误报、漏报、左右方位与提示延迟 |
| 异常恢复 | 暂停、恢复网络、退出再进入 | 相机是否恢复、是否残留过期提示 |

## 遇到问题

记录安装包版本、手机型号、测试时间、网络方式、地图路线、具体位置和操作步骤。
复制导航诊断或避障识别诊断，附截图；由维护者在同一时间段查服务器日志。
分享前检查记录中是否包含个人信息，不提供密码或管理密钥。

网站本身的构建检查，只验证文档是否完整、站内链接是否有效。
上述手机、网络及实际走廊测试仍需要真机完成。

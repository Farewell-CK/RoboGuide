# Original documents and acceptance archives

These sources retain architecture authority, decisions and historical evidence. Start with the [tour](architecture-tour.md). Maintained guides are bilingual; archives retain their original language. Switching to English does not imply full historical translation.

| Archive topic | Meaning and limits | Original sources |
| --- | --- | --- |
| V2 architecture | Authoritative baseline and implementation topology; the DOCX is historical | [V2](docs/architecture/v2/index.md) |
| Decisions | Original numbers/status and rationale; Accepted is not complete acceptance | [Topics](decisions.md), [catalog](docs/decisions/index.md) |
| Implementation audit | Separates implementation, wiring, software acceptance and deployment gaps | [Latest inventory](docs/development/roboguide-branch-audit-2026-10-22.md) |
| Memory / scoped revision | Original permission, import/use/revoke, nonempty Memory and independent goal proof | [MI/Memory composition](docs/development/acceptance/2026-10-21-runtime-mi-scoped-memory.md) |
| References and recovery | Active refs match original-provider CAS; no global coverage claim | [Reference recovery](docs/development/acceptance/2026-10-21-recovery-active-content-reference.md) |
| Deployment and monitoring | Zero-Node inspector and actual software monitoring; no hardware or long-term SLO | [Deployment](docs/development/acceptance/2026-10-21-deployment-profile.md), [monitoring](docs/development/acceptance/2026-10-20-observability.md) |
| Experiments | Denominators, frozen code/model, official metrics and unavailable cases | [Eval Harness](evaluation/index.md) |
| Historical architecture | V1.1 and original design, not current capability inventory | [V1.1](docs/architecture/v1.1/index.md) |

The [repository index](docs/index.md) links remaining sources. Meeting notes, temporary files and local experiment results are excluded from recursive publication.

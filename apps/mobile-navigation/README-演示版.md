# 0.9.92 演示版

在 0.9.91 五方向视觉提示版的独立副本上修改，原目录和 APK 保留。

## 页面

页面保留相机画面、导航播报文本、左右前方距离、局部地图、相机和标定准备状态、目的地与路线操作。

页面最底部为“更多信息与设置”。感知与 A* 调试信息、定位朝向详情、大模型五方向详情、大模型调试信息、接口设置各有独立显示开关，默认折叠，记住用户选择。隐藏这些区域只改变显示，不停止任何计算。

大模型功能开关也在最底部：没有保存设置时默认开启；已有用户开关选择优先，升级不会强制重新开启用户关闭的功能。开启后会把低频 D455 彩色画面上传至已配置的千问兼容接口。

## 对接外部播报

继续读取原 TextView：`com.elabrador.mobilenavigation.npu:id/guidanceText`。
无需接入新的 TTS。该框是最终完整播报句子，例如：

- 直走，左侧有行人
- 右转30度，正前方有电动车
- 停止，正前方有车辆
- 直走，左侧、左前方有围栏

方向在最前面，具体物体在后面；没有物体时只显示方向。“无”、泛称“其他实体”、网络和调试文字不进入该框。多个方向有相同物体集合时合并方位，物体排列固定，避免仅因返回顺序变化重复触发朗读。保留原转角信息，将度数符号转成“度”便于朗读。

大模型每次成功返回新图像的有效结果后才更新场景。物体消失需要两次不同图像的结果确认；同一方向下仅物体信息变化，最多每 3 秒改变播报文本一次。方向变化优先，停止立即输出；大模型更新不能突破方向时序。无导航指令时文本框为空。

网络失败、超时和结果过期不会自行重写播报框。同一句持续显示期间保留原文字；下一次方向改变时，超过 5 秒的物体结果不会重新拼入新指令。五方向详情仍保留上次有效结果，副框说明时间与错误原因。

## 转向时序

- 当前指令发布后，新的转向至少等满 5 秒才可替换，采用届时最新方向，不排队播报旧转向。
- 新鲜安全规划判定为直走，可以立即接替左转、右转、向后转；恢复直走后重新开始 5 秒转向间隔。
- 停止立即生效。
- 停止恢复需要新鲜安全结果持续确认 1.5 秒，重复绘制同一帧不算新证据；直走也不能跳过此确认。
- 原 A*、地图、代价、路径保持、VINS、地理标定算法未修改。

## 构建

本地提供 Android SDK 的 local.properties。可用环境变量 QWEN_CONFIG 指向源码以外的私密配置：

```properties
key=填写API Key
endpoint=https://填写兼容接口地址
model=qwen3-vl-flash
```

执行 `gradlew :app:testNpuDebugUnitTest :app:assembleNpuDebug`。
本次 187 项单元测试通过，包括转向 5 秒边界、直行提前接替、停止确认、新帧识别与文本组合测试。未连接手机，本版尚需现场验证实际显示与外部朗读行为。

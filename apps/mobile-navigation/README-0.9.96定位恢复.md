# 0.9.96 自动同向标定与定位恢复版

基于 0.9.95 独立复制修改；本文件是本次版本说明，其他带版本号的说明为历史记录。

## 使用效果

- 手机 GPS、网络定位都可提供地点搜索、步行规划和路线跟随位置。
- 不再要求定位精度优于 15 米，也不再因为定位超过 5 秒就阻止规划或输出提示。
- 输入地址显示候选地点，选中地点后自动请求步行路线并开始导航。第一次定位到达后会自动重试等待中的搜索。
- 仍保留有效经纬度校验、位置时间顺序和路线进度连续性保护。启动时只将 30 秒内的系统缓存位置送入导航；运行中等待下一位置时沿用上次位置，这与旧同向定位流程一致。
- 报告精度较差的位置不会被精度门槛直接挡住，但位置本身仍可能偏移，进度与到达判断也受影响。放宽门槛不代表定位变准。

## 自动同向标定

启动阶段保持手机顶部与 D455F 镜头前方同向。VINS 初始化、手机方向及磁偏角修正位置具备后，自动完成一次方向对齐并锁定，不需要采集 17 点、不需要点标定按钮。完成后可分别转动手机和相机。

VINS 重启后会重新自动对齐，需要再次同向。这个流程没有消除 VINS 自身初始化，也不能自动判断手机与相机是否摆放同向；磁干扰仍可能影响方向。

## 保留的功能

A*、地图代价、路径保持、VINS 核心、转向 5 秒限制、直行提前接替、停止立即生效与恢复安全确认 1.5 秒、千问具体物体提示、合并播报文本和折叠界面不变。地图和 VINS 的安全时效检查仍保留。

## 构建

运行 `:app:testNpuDebugUnitTest :app:assembleNpuDebug`。默认使用随源码提供的 arm64-v8a 原生库；NPU 模型位于 app/src/npu/assets/models。私密 API 配置从构建机外部 QWEN_CONFIG 文件读取，不包含在交付源码中。此演示 APK 包含已配置的服务访问参数，仅用于现有演示分发，不上传 GitHub。

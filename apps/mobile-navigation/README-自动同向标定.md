# 0.9.93 自动同向标定版

基于 0.9.92 的独立副本，只替换默认方向标定流程。旧版 17 点轨迹 APK 和源码保留。

使用：
1. 启动阶段保持手机顶部与 D455F 镜头前方同向。
2. 等待 VINS 初始化、手机方向传感器数据，以及一次有效位置（用于磁北到真北的磁偏角修正）。
3. 条件齐备后自动完成一次同向标定并锁定，无需点按钮，也无需步行采集 17 个轨迹点。
4. 显示完成后可以分别转动手机和相机。

VINS 重启会使方向对齐失效，并自动等待重新同向对齐。这个阶段需要再次保持手机与相机同向。手机方向超过 2 秒或 VINS 位姿超过 1.5 秒等无效输入不会用于完成对齐；没有有效位置时等待真北修正。GPS 步行路线定位门槛保持原版。

自动同向标定使用手机指南针和 D455F VINS 朝向，不会自动检测设备是否真正同向，也无法保证消除磁干扰。它省去 17 点方向轨迹标定，不改变 VINS 自身初始化。偏角只用于本次 VINS 坐标系，不永久套用到下次进程启动。

以下与 0.9.92 相同：
- A*、地图代价、路径保持与 VINS 核心；
- 转向 5 秒限制、直行提前接替、停止立即生效和恢复安全确认 1.5 秒；
- 千问具体物体提示、合并文本、底部折叠设置；
- 全部 arm64-v8a 原生库和 NPU 模型。

191 项单元测试通过，包含新增自动同向标定的左右符号、锁定、重启失效、旧输入拒绝测试。APK 编译成功。未连接手机，尚未完成真机同向摆放与磁场环境测试。

源码不包含私密 API 配置。测试 APK 使用原外部配置编译。接口配置方式参见 README-演示版.md。

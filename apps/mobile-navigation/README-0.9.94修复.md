# 0.9.94 自动同向标定等待修复

手机现场发现：0.9.93 的 VINS 已正常输出，但界面一直等待真北修正位置。手机有精度约 33 米的网络定位，GPS 为较旧的约 40 米精度位置；旧代码只使用经过导航精度门槛的 GPS，导致磁偏角修正位置为空。

修复：PhonePoseTracker 额外提供仅用于磁偏角修正的位置回调，在导航过滤之前接收 GPS、网络或缓存位置。独立 DeclinationPosition 只接受有限有效经纬度、报告精度不超过 5 公里、年龄不超过 1 小时、非未来和递增时间的数据。粗位置不写入导航 lastLocation，不经过或改变 A* 的定位逻辑。

自动同向标定仍需要新鲜手机方向、新鲜且已初始化的 VINS 位姿。开始和 VINS 重启时保持手机顶部与镜头前方同向，完成后锁定。界面分别显示等待手机方向、等待真北修正位置，便于判断原因。

193 项测试通过，包括粗定位可用于磁偏角但仍被导航定位门槛拒绝、缓存过期和异常时间拒绝等测试。8 个 arm64-v8a 原生库打包检查通过。

之前 APK 和源码保留。无 GitHub 上传。

# 千问五方向视觉提示版

当前版本参见 [演示版说明](README-演示版.md)。以下为五方向详情框的数据规则；该框已移至底部，按需展开。

这条云端视觉链路只更新新增的提示区域，不读取或修改语义分割、深度建图、OctoMap、Costmap、A*、VINS 或原导航指令。

## 主要提示

主要提示始终固定显示五行：

- 左侧
- 左前方
- 正前方
- 右前方
- 右侧

每次收到可用的新识别结果后，五行作为同一份完整快照一起刷新。没有检测到实体障碍的方向显示“无”。网络失败、服务超时、返回内容不可解析、画面不可可靠判断以及结果超过 5 秒未更新时，主要提示继续保留最后一次有效结果。

## 调试信息

调试框显示当前分析状态、网络或接口错误、画面是否可判断、最后一次有效结果的年龄、请求耗时以及结果是否超过 5 秒未更新。这些文字不会进入主要提示，也不会影响原导航系统。

## 密钥与构建

源码不保存 API Key。开发构建可以在项目根目录创建不提交的 `qwen.private.properties`，或使用环境变量 `QWEN_CONFIG` 指向外部配置文件：

```properties
key=请填写API Key
endpoint=https://请填写兼容接口地址
model=qwen3-vl-flash
```

未在构建时提供配置也可以编译；安装后可在“视觉提示设置”中填写。
